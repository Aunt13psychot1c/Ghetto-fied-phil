## 🎮 How to play

1. **Step into the circle.** You start with a balance of virtual cash (the game screen shows $100).
2. **Set your bet.** Move the slider to decide how much play money you're risking.
3. **Shoot two dice.** The first throw is the **come-out roll**.
4. **Read the roll.** A 7 or 11 wins; a 2, 3, or 12 loses; anything else creates a point.
5. **If there's a point, keep shootin'.** Roll that same point again **before a 7** to win. Roll a 7 first, and the bet is lost. Any other roll means shoot again.
6. **Won? MOVE!** Hit **GRAB THE CASH!** before Phil's timer runs out. If you're too slow, he grabs your winnings instead.

| Come-out dice total | Result | What happens next |
| :---: | :--- | :--- |
| **7 or 11** | 🎉 Win | Race Phil for the winnings |
| **2, 3, or 12** | 💀 Lose | Bet is deducted |
| **4, 5, 6, 8, 9, or 10** | 🎯 Set point | Keep rolling |

**With a point active:** point again = win · 7 = lose · any other total = roll again.

### A tiny heads-up about Discord

A live Websim page is a place to **play**. A Discord **Interactions Endpoint URL** needs a server that receives Discord POST requests and verifies their signatures. Those can use the same branded domain, but serving HTML alone does not provide that backend. Keep the endpoint field blank until a working interaction service exists.
